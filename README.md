# Knihovna Redux

Реінженірінг системи інтернет-магазину книг (PHP + MySQL) у межах курсової роботи з дисципліни «Розробка та реінженірінг програмних систем».

## Про вихідну систему

Knihovna - веб-сайт (CMS) для інтернет-магазину книг: каталог із пошуком і фільтрами, реєстрація та авторизація, кошик і оформлення замовлень, історія замовлень, звернення до підтримки, адмін-панель для керування книгами.

Вихідна версія створена у 2024 році як курсова робота з дисципліни «Backend-розробка»: https://github.com/VadymLeus/Knihovna

Стек вихідної системи: PHP (власна реалізація MVC), MySQL (mysqli), HTML/CSS/JavaScript, WampServer.

## Мета

Перевести систему в сучасну, підтримувану форму зі збереженням її функціональності, а результат підтвердити тестами та метриками «до/після».

## Версії (git-теги)

- `v0` — вихідний код без змін (baseline)
- `v0.1-runnable` — мінімальні правки для відновлення запуску
- `v1.0` — реструктуризація, функціональність без змін
- `v2.0` — покращення функціональності

## Статус

Поточний етап: baseline (`v0`).
